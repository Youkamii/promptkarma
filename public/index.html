배지는 나중.다음 요청부터.

AI가 같은 내용을 되묻거나 수정이 빙빙 돈 세션 뒤에 실행해보세요. Claude Code 로그를 내 컴퓨터에서만 읽고, 다음 요청에서 시험해볼 작성 습관 하나를 제안합니다.

원문 전송 없음 LLM 없음 설명 가능한 규칙 선택형 공유
npx로 실행하기 측정 규칙 보기
01 · OBSERVE

사람이 쓴 입력만 골라냅니다

도구 출력, 자동 주입, 긴 붙여넣기와 중복 기록을 빼고 실제 프롬프트의 집계값만 남깁니다.

02 · EXPLAIN

관찰 신호를 나눠 봅니다

맥락, 조건, 단계, 기준 없는 통째 위임 표현이 얼마나 보였는지 재현 가능한 규칙으로 따로 보여줍니다.

03 · TRY NEXT

한 번에 하나만 바꿉니다

낮게 관찰된 항목을 부족함으로 판정하지 않고, 다음 요청에서 한 번 시험해볼 후보 하나로 제안합니다.

이건 검증 자격증이 아닙니다.

공개값은 사용자가 올린 집계 숫자이며 현재 GitHub 계정 소유권과 로그 진위를 확인하지 못합니다. 그래서 카드에 SELF-REPORTED를 표시합니다. 표본이 30개보다 적으면 요약 대신 수집 중 상태만 보여줍니다.

설치 없이 바로 스캔합니다.

Node.js 22가 설치된 컴퓨터에서 실행하세요. 첫 실행에서는 npm이 패키지를 내려받고, 프롬프트 원문은 서버로 보내지 않습니다.

npx --yes promptkarma scan
npx --yes promptkarma scan --explain
