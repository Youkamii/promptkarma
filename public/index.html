숫자 두 개가,
당신만의 도형이 됩니다.

AI를 대하는 태도는 KARMA 색으로, 지시의 구조와 도구 활용은 INTELLECT 도형으로 바뀝니다. 설명표를 읽지 않아도 모양과 색만으로 서로 다른 배지가 됩니다.

01 / SCAN

원문은 로컬에서만

사람이 쓴 프롬프트만 골라 집계하고 원문은 버립니다. 도구 출력, 자동 입력, 긴 붙여넣기는 제외합니다.

02 / SHAPE

도형과 색으로 바꾸기

구조화 지수는 일곱 단계 다포체가 되고, 욕설 발생률은 적색에서 청록까지 이어지는 오라가 됩니다.

03 / SHARE

프로필에 붙이기

README 코드를 한 번 붙여두면 같은 주소가 유지됩니다. 다시 스캔하고 제출할 때 배지만 갱신됩니다.

설치 없이,
명령 한 줄로.

Node.js 22가 설치된 컴퓨터에서 실행하세요. 현재는 Claude Code의 로컬 세션을 읽습니다. 공개 카드는 원할 때만 별도로 올립니다.

TERMINAL / QUICK START
$ npx --yes promptkarma scan
$ npx --yes promptkarma card me

# 공개 배지가 필요할 때만
$ npx --yes promptkarma submit <github-username>
